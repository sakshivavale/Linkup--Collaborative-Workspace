Implements US-LIVE-03: Video Grid with Participant Tiles.

Changes:
- Adds `ParticipantTile` and `VideoGrid` components under `client/src/features/rooms/`.
- Integrates VideoGrid into `LiveTab.tsx`, derives participants from `useRoom` presence, listens for `presence:update` and `live:active-speaker`.

Acceptance Criteria:
- Each participant tile shows name, mute icon when mic is off, and camera-off icon when camera is off.
- Active speaker is highlighted with a ring.
- Tiles update dynamically as participants join/leave via `presence:update`.

Testing steps:
1. Start server: `npm run dev --workspace=server`
2. Start client: `npm run dev --workspace=client`
3. Open two browser windows, join same room, verify tiles appear/remove and active speaker highlight on `live:active-speaker`.
